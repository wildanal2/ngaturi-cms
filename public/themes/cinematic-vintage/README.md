# Cinematic Vintage artwork

Original, lightweight vector artwork drawn for Ngaturi. No reference-video assets or couple photos are included.

- `backgrounds/damask.svg`: repeating heritage wall pattern.
- `frames/heritage.svg`: main decorative frame.
- `frames/event-portal.svg`: ceremonial arch for editable events.
- `frames/gallery.svg`: lighter secondary photo frame.
- `florals/branch.svg` and `florals/foreground.svg`: side and foreground layers.
- `architecture/colonnade.svg` and `architecture/chandelier.svg`: pelaminan depth.
- `effects/dust.svg` and `effects/glow.svg`: grain and focal light.

Masks inherit the invitation palette through CSS. User photos come exclusively from hydrated section props.
